## AUTHENTICATION FLOW IMPLEMENTATION

### Cookie Handling for Expo Mobile Apps

**Install Required Package:**
```bash
npm install @react-native-cookies/cookies
```

**Supabase Client Setup:**
```typescript
import AsyncStorage from '@react-native-async-storage/async-storage';
import CookieManager from '@react-native-cookies/cookies';
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
  {
    auth: {
      storage: AsyncStorage,
      autoRefreshToken: true,
      persistSession: true,
      detectSessionInUrl: false,
    },
  }
);

// After successful login, sync cookies
const syncCookies = async (session: any) => {
  await CookieManager.set('https://appv2.referredby.com.na', {
    name: 'sb-access-token',
    value: session.access_token,
    path: '/',
    secure: true,
    httpOnly: true,
  });
};
```

**Login Function Example:**
```typescript
async function handleLogin(email: string, pin: string) {
  try {
    // Step 1: Sign in with Supabase
    const { data, error } = await supabase.auth.signInWithPassword({
      email: email,
      password: pin, // PIN is stored as password
    });

    if (error) throw error;

    // Step 2: Sync cookies
    if (data.session) {
      await syncCookies(data.session);
    }

    // Step 3: Fetch user profile
    const response = await fetch('https://appv2.referredby.com.na/api/users/me', {
      headers: {
        'Authorization': `Bearer ${data.session.access_token}`
      }
    });

    const userData = await response.json();

    // Step 4: Navigate to profile page
    navigation.navigate('Profile', { user: userData.user });

  } catch (error) {
    console.error('Login failed:', error);
    Alert.alert('Login Failed', error.message);
  }
}
```

## ERROR HANDLING

**Network Errors:**
```typescript
try {
  const response = await fetch(API_URL);
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}: ${response.statusText}`);
  }
  const data = await response.json();
  return data;
} catch (error) {
  Alert.alert('Network Error', 'Unable to connect to server. Please check your internet connection.');
  console.error(error);
}
```

**Authentication Errors:**
- 401 Unauthorized → Show "Invalid credentials" message
- 403 Forbidden → Redirect to login
- Session expired → Redirect to login with message

## Complete Example: Full User Flow

```typescript
import { createClient } from '@supabase/supabase-js';
import AsyncStorage from '@react-native-async-storage/async-storage';

// Initialize Supabase
const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
  {
    auth: {
      storage: AsyncStorage,
      autoRefreshToken: true,
      persistSession: true,
    },
  }
);

// 1. Login
async function login(email: string, pin: string) {
  const { data, error } = await supabase.auth.signInWithPassword({
    email,
    password: pin,
  });
  
  if (error) throw error;
  return data.session;
}

// 2. Get Profile
async function getProfile(accessToken: string) {
  const response = await fetch('https://appv2.referredby.com.na/api/users/me', {
    headers: { 'Authorization': `Bearer ${accessToken}` }
  });
  
  if (!response.ok) throw new Error('Failed to fetch profile');
  return await response.json();
}

// 3. Get Interest Confirmation
async function getInterestConfirmation(accessToken: string, loanType: 'nano' | 'term') {
  const response = await fetch(
    `https://appv2.referredby.com.na/api/loans/interest-confirmation?type=${loanType}`,
    {
      headers: { 'Authorization': `Bearer ${accessToken}` }
    }
  );
  
  if (!response.ok) throw new Error('Failed to fetch interest confirmation');
  return await response.json();
}

// Example usage
async function handleUserLogin() {
  try {
    // Step 1: Login
    const session = await login('mw@wet.com', '1234');
    
    // Step 2: Get Profile
    const profileData = await getProfile(session.access_token);
    console.log('User Profile:', profileData.user);
    
    // Step 3: Get Interest Confirmation
    const interestData = await getInterestConfirmation(session.access_token, 'nano');
    console.log('Interest Details:', interestData.confirmation);
    
  } catch (error) {
    console.error('Error:', error);
  }
}
```

## Error Handling

All endpoints return errors in this format:

```json
{
  "success": false,
  "error": "Error message here"
}
```

**Common Status Codes:**
- `200` - Success
- `400` - Bad Request (invalid parameters)
- `401` - Unauthorized (invalid credentials or expired session)
- `403` - Forbidden (insufficient permissions)
- `404` - Not Found
- `500` - Server Error
