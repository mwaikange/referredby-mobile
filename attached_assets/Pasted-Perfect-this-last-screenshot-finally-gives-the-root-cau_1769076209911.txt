## 🧠 WHY THIS HAPPENED (IMPORTANT CONTEXT)

This happens when **one of these is true**:

1. The dev installed `react@19.x` manually
2. Expo SDK expects a **specific React version**, but `package.json` drifted
3. Dependencies were installed with mismatched peer versions
4. `npm install` / `yarn add` was run without respecting Expo’s version matrix

⚠️ Expo **locks React + React Native versions**.
You **cannot freely upgrade React** like in web apps.
