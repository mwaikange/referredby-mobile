## API ENDPOINTS (ALL READY)

### 1. Statement Endpoint
```
GET /api/mobile/statement?user_id={user_id}
```

**Response Structure:**
```json
{
  "success": true,
  "loan": {
    "loan_id": "NL12345",
    "status": "PU",
    "borrowed_amount": 2000.00,
    "interest_rate": 28.00,
    "interest_fee": 560.00,
    "processing_fee": 32.00,
    "total_repayable": 2592.00,
    "outstanding_amount": 0.00,
    "amount_paid": 2592.00,
    "due_date": "2025-12-15",
    "outstanding_date": null,
    "grace_date": null,
    "paid_date": "2025-12-10",
    "lending_society_id": "uuid",
    "user_id": "uuid",
    "created_at": "2025-11-15T10:00:00Z"
  },
  "loan_type": "nano",  // or "term"
  "is_active": false,   // true if DU/OT/BL, false if PU
  "is_paid_up": true    // true if status is PU
}
```

**Logic:**
1. Checks nano active loans (DU, OT, BL)
2. Checks term active loans (DU, OT, BL)
3. Checks nano paid-up loans (PU)
4. Checks term paid-up loans (PU)
5. Returns most recent (by created_at)

## MOBILE APP IMPLEMENTATION

### Statement Screen

```dart
// Example implementation
Future<void> fetchStatement() async {
  try {
    final response = await http.get(
      Uri.parse('https://appv2.referredby.com.na/api/mobile/statement?user_id=$userId'),
    );

    if (response.statusCode == 200) {
      final data = json.decode(response.body);
      
      // CHECK IF SUCCESS
      if (data['success'] == true && data['loan'] != null) {
        final loan = data['loan'];
        final loanType = data['loan_type']; // "nano" or "term"
        final isActive = data['is_active']; // true/false
        final isPaidUp = data['is_paid_up']; // true/false
        
        // UPDATE UI WITH LOAN DATA
        setState(() {
          loanId = loan['loan_id'];
          borrowedAmount = loan['borrowed_amount'];
          interestRate = loan['interest_rate'];
          interestFee = loan['interest_fee'];
          processingFee = loan['processing_fee'];
          totalRepayable = loan['total_repayable'];
          outstandingAmount = loan['outstanding_amount'];
          amountPaid = loan['amount_paid'];
          dueDate = loan['due_date'];
          paidDate = loan['paid_date'];
          status = loan['status'];
          
          // Show different UI based on status
          if (isActive) {
            showPaymentButton = true;
            statusText = "ACTIVE LOAN";
          } else if (isPaidUp) {
            showPaymentButton = false;
            statusText = "PAID UP LOAN";
          }
        });
      } else {
        // NO LOANS AT ALL - show "No Active Loans" screen
        setState(() {
          showNoLoansScreen = true;
        });
      }
    } else {
      // Handle error
      showError('Failed to fetch statement');
    }
  } catch (e) {
    showError('Error: $e');
  }
}
```

## COMMON ERRORS TO AVOID

### ❌ WRONG: Checking only nano_loans table
```dart
// This will miss term loans
final nano = await fetchNanoLoan(userId);
if (nano == null) showNoLoans();
```

### ✅ CORRECT: Using the unified statement endpoint
```dart
// This checks both nano AND term loans with proper fallback
final statement = await fetchStatement(userId);
```

### ❌ WRONG: Not handling paid-up loans
```dart
// Only checking active status
if (status == 'DU' || status == 'OT' || status == 'BL') {
```
