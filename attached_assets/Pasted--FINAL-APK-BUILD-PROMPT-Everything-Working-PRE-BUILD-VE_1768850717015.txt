## 🔄 IF BUILD FAILS

Common issues and solutions:

### Error: "Missing app.json configuration"
**Solution:** Ensure app.json has all required Android fields

### Error: "Expo account required"
**Solution:** Run `eas login` and create free Expo account

### Error: "Gradle build failed"
**Solution:** Use EAS Build instead of local build

### Error: "Environment variables not found"
**Solution:** Verify EXPO_PUBLIC_ prefix is used in code, not VITE_
