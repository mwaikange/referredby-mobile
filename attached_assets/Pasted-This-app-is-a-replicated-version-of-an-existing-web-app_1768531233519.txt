1️⃣ CREATE A GLOBAL RESPONSIVE CONTAINER (MANDATORY)

Create or update a reusable layout container and apply it to ALL pages, including /profile.

Rules:

Center content horizontally

Add proper left & right padding on all devices

Prevent UI from touching screen edges

Implement:

  width: 100%;
  margin: 0 auto;
  padding-left: 16px;
  padding-right: 16px;

  }

    max-width: 900px;
    padding-left: 32px;

  }
