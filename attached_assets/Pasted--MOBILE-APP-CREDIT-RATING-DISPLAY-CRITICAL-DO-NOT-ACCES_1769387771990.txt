# MOBILE APP - CREDIT RATING DISPLAY

## ⚠️ CRITICAL: DO NOT ACCESS SUPABASE DIRECTLY

Your mobile app should **NEVER** connect to Supabase directly. Always use the backend API endpoints.

---

## 📡 SINGLE ENDPOINT FOR ALL RATING DISPLAYS

Use this ONE endpoint for both Profile page AND Credit Score History page:

```
GET https://appv2.referredby.com.na/api/mobile/credit-rating?user_id={user_id}
```

### Request
```
GET /api/mobile/credit-rating?user_id=77a3adee-5734-4bb1-b0bc-d0d6166af205
```

### Response
```json
{
  "success": true,
  "rating": 1.5,           // ⭐ USE THIS FOR STARS (0-10 scale, supports decimals)
  "score": 15,             // Total points (0-100)
  "label": "POOR",         // POOR, FAIR, GOOD, EXCELLENT
  "breakdown": {
    "early_payments": 5,
    "on_time_payments": 10,
    "late_penalties": 0,
    "referral_bonus": 0
  },
  "lifetime": {
    "points_earned": 15,
    "penalties_incurred": 0
  }
}
```

---

## ⭐ HOW TO DISPLAY STARS

### Rule: Use `rating` field (0-10 scale)

**Examples:**
- `rating: 0` → Show 0 stars (☆☆☆☆☆☆☆☆☆☆)
- `rating: 1.5` → Show 1.5 stars (★★☆☆☆☆☆☆☆☆)
- `rating: 2.5` → Show 2.5 stars (★★★☆☆☆☆☆☆☆)
- `rating: 5.0` → Show 5 stars (★★★★★☆☆☆☆☆)
- `rating: 10.0` → Show 10 stars (★★★★★★★★★★)

### Mobile Implementation (Example in Dart/Flutter)
```dart
// Fetch rating
final response = await http.get(
  Uri.parse('https://appv2.referredby.com.na/api/mobile/credit-rating?user_id=$userId')
);
final data = jsonDecode(response.body);
double rating = data['rating']; // e.g., 1.5

// Display stars
Widget buildStars(double rating) {
  List<Widget> stars = [];
  for (int i = 0; i < 10; i++) {
    if (rating >= i + 1) {
      stars.add(Icon(Icons.star, color: Colors.amber)); // Full star
    } else if (rating > i && rating < i + 1) {
      stars.add(Icon(Icons.star_half, color: Colors.amber)); // Half star
    } else {
      stars.add(Icon(Icons.star_border, color: Colors.grey)); // Empty star
    }
  }
  return Row(children: stars);
}
```

## ❌ COMMON MISTAKES

1. **DON'T** access Supabase directly from mobile app
2. **DON'T** calculate rating yourself from events
3. **DON'T** use different endpoints for profile vs credit history
4. **DON'T** hardcode rating values
5. **DON'T** use `score` field for stars (that's 0-100 points)

## ✅ CORRECT APPROACH

1. **DO** call `/api/mobile/credit-rating` endpoint
2. **DO** use the `rating` field for star display
3. **DO** use the same endpoint for both screens
4. **DO** refresh data when user returns to screen
5. **DO** use `rating` (0-10) not `score` (0-100)

---

## 📞 TROUBLESHOOTING

**Problem:** Stars show different values on different screens
- **Solution:** Both screens must call the same endpoint

**Problem:** Stars always show 0
- **Solution:** Check you're using `data.rating` not `data.score`

**Problem:** Can't connect to Supabase
- **Solution:** Don't connect directly - use the API endpoint instead

**Problem:** Rating is 15 instead of 1.5
- **Solution:** You're using `score` (points) instead of `rating` (stars)
