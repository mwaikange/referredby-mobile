# CRITICAL: All Mobile API Endpoints Need Bearer Token Support

## 🎯 THE ISSUE

**ALL mobile API endpoints** currently only accept cookie-based authentication (for web apps), but mobile apps send Bearer tokens in the Authorization header.

This affects **every endpoint** the mobile app needs to use:
- ❌ `/api/users/me` - Returns 401
- ❌ `/api/mobile/interest-confirmation` - Will return 401
- ❌ `/api/mobile/loan-request` - Will return 401
- ❌ `/api/mobile/credit-score-history` - Will return 401
- ❌ Any other authenticated endpoint

## 🔧 THE SOLUTION: Create a Reusable Auth Helper

Instead of fixing each endpoint individually, create **ONE helper function** that all endpoints can use.

### Step 1: Create Authentication Utility

**File:** `/lib/auth/mobile-auth.ts`

```typescript
import { createClient } from '@/lib/supabase/server';
import { NextResponse } from 'next/server';

/**
 * Universal authentication function for both web and mobile apps
 * Checks for Bearer token (mobile) or cookies (web)
 * 
 * @param request - The incoming request
 * @returns Object with { user, session, error, response }
 */
export async function authenticateRequest(request: Request) {
  try {
    // Check for Authorization header (mobile apps)
    const authHeader = request.headers.get('authorization');
    const bearerToken = authHeader?.replace('Bearer ', '');
    
    const supabase = createClient();
    
    if (bearerToken) {
      // MOBILE APP: Use Bearer token
      console.log('📱 Mobile app authentication (Bearer token)');
      
      const { data, error } = await supabase.auth.getUser(bearerToken);
      
      if (error || !data.user) {
        console.error('❌ Invalid Bearer token:', error?.message);
        return {
          user: null,
          session: null,
          error: 'Invalid authentication token',
          response: NextResponse.json(
            { success: false, error: 'Invalid authentication token' },
            { status: 401 }
          ),
        };
      }
      
      return {
        user: data.user,
        session: { user: data.user }, // Minimal session object
        error: null,
        response: null,
      };
      
    } else {
      // WEB APP: Use cookies
      console.log('🌐 Web app authentication (cookies)');
      
      const { data: { session }, error } = await supabase.auth.getSession();
      
      if (error || !session) {
        console.error('❌ No valid session in cookies:', error?.message);
        return {
          user: null,
          session: null,
          error: 'Unauthorized. Please log in.',
          response: NextResponse.json(
            { success: false, error: 'Unauthorized. Please log in.' },
            { status: 401 }
          ),
        };
      }
      
      return {
        user: session.user,
        session: session,
        error: null,
        response: null,
      };
    }
    
  } catch (error) {
    console.error('❌ Authentication error:', error);
    return {
      user: null,
      session: null,
      error: 'Authentication failed',
      response: NextResponse.json(
        { success: false, error: 'Internal server error' },
        { status: 500 }
      ),
    };
  }
}
```

### Step 2: Update ALL Endpoints to Use This Helper

Now every endpoint just needs **3 lines** to handle authentication:

#### Example 1: `/api/users/me/route.ts`

```typescript
import { authenticateRequest } from '@/lib/auth/mobile-auth';
import { createClient } from '@/lib/supabase/server';
import { NextResponse } from 'next/server';

export async function GET(request: Request) {
  // Universal authentication (works for web + mobile)
  const auth = await authenticateRequest(request);
  if (auth.error) return auth.response; // Return 401 if not authenticated
  
  // User is authenticated - proceed with business logic
  const userId = auth.user.id;
  
  try {
    const supabase = createClient();
    const { data: user, error } = await supabase
      .from('users')
      .select(`
        *,
        lending_societies!lending_society_id(name),
        partner_staff!referring_partner(staff_code, first_name, last_name)
      `)
      .eq('auth_user_id', userId)
      .single();
    
    if (error) {
      return NextResponse.json(
        { success: false, error: 'User not found' },
        { status: 404 }
      );
    }
    
    // Format and return response
    const response = {
      ...user,
      lending_society_name: user.lending_societies?.name || null,
      referring_partner_name: user.partner_staff 
        ? `${user.partner_staff.first_name} ${user.partner_staff.last_name}`
        : null,
    };
    
    delete response.lending_societies;
    delete response.partner_staff;
    
    return NextResponse.json(response, { status: 200 });
    
  } catch (error) {
    console.error('❌ Error:', error);
    return NextResponse.json(
      { success: false, error: 'Internal server error' },
      { status: 500 }
    );
  }
}
```
